# STL Viewer

Aplicação React + Vite + TypeScript para visualização de arquivos STL e marcação de pontos em modelos 3D.

## Primeira instalação

No diretório do projeto, execute:

```bash
npm install
```

## Executar localmente

```bash
npm run dev
```

A aplicação ficará disponível no navegador no endereço informado pelo Vite.

## Build para produção

```bash
npm run build
```

## Estrutura principal

- `src/components/STLViewer.tsx` — componente principal do visualizador STL
- `src/App.tsx` — entrada da aplicação
- `public/` — arquivos públicos
